## 25 Oct 2026 — approved Craft interface gallery

The native project now uses 50 original, source-verified UI screenshots across
16 exact project IDs: three previously embedded curated frames and 47
previously reviewed **unaltered Craft screenshots** for 13 managed apps. The
Craft assets are from the pinned `craft-suite-media.v1.json` and checked-in
`assets/media/craft/screenshots/`; upstream licensing and per-image attribution
remain in `CRAFT_SUITE_MEDIA_NOTICES.md` and `craft-suite-{MIT,Apache-2.0}.txt`.
The 47 frames were not retrieved via a scraping service, hotlinked, upscaled,
or generated as mock interfaces. Exact original SHA256 digests and lengths are
revalidated offline by `sync-approved-gallery.mjs --check`. The generator
produces the Slint `ApprovedGalleryThumb` and `ApprovedGalleryShot` components,
Rust media count/source allowlist, and a JSON evidence index. Every image is
bound to the exact `managed:app` + original source identity in `media_id()`.

The UI's `View source` action is constrained to the precise GitHub source URL
for a known gallery frame; no arbitrary external URLs or install permissions
are derived from the images. Runtime images are embedded in the native binary;
no remote image request occurs on browse. Portable packages include the
existing third-party media notices and license texts beside the Node license.
For the complete 181-project coverage list see `docs/visual-catalog/`.


## 25 Oct 2026 — independent curated visual source wave

The second native source-verified wave adds 20 authentic application interface
screenshots for 13 new curated project IDs and eight native icons, one icon-only.
The unique screenshot project coverage is now 29; embedded frames 70 and
source-checked native icons 30. These selected original files are pinned to
specific upstream GitHub commits by `independent-media.v1.json` and explicitly
selected in `independent-native-selection.v1.json`. Only
`reviewStatus=repository-confirmed` projects with a reported repository license
were eligible; three unverified research-candidate upstream entries were
**excluded** even though their downloaded bytes passed checksum validation.

The native gallery generator confirms every original SHA-256, file length,
image dimension, path, pinned commit and source URL completely offline. Rust
routes media only when both the exact curated project ID and upstream repository
match the preapproved mapping. Any research entry, lookalike fork, unknown
license or missing asset gets a neutral fallback. Neither browsing nor CI downloads
remote imagery. The checked-in assets are unmodified; no artificial screenshots.

Source-reported repository licenses are **not** necessarily a standalone image,
artwork or trademark redistribution grant. The generated
`INDEPENDENT_NATIVE_MEDIA_NOTICES.md` records all pinned source/commit/sha and
reported repository license metadata. Public distribution must remain blocked
pending a separate legal/license audit. Preview packaging carries this notice,
but cannot be assumed legally cleared for release solely from this review.

## In-app source credit and publication guard

The generator `sync-approved-gallery.mjs` now derives visible, source-specific
attribution for every one of the 70 screenshot frames and 30 embedded official
icons. It records the upstream repository URL, source-reported repository
license, original content SHA-256 and explicitly unresolved media/mark rights.
The notice appears directly in native details, with an exact original source
link for each displayed screenshot. The complete generated JSON/Markdown
credit ledger is bundled with the native developer-preview packages.

`media-rights-gate.mjs` is executed by the offline native media verifier and
portable CI manifest generator. It refuses missing/malformed credits and
refuses public release when only attribution is known. This is deliberately not
a claim that repository licenses, origin citations or modified UI layouts
resolve third-party rights. The 152 no-screenshot catalog items remain
available as text/metadata, without fabricated screenshots.
